# 🚀 DataLens AI

An AI-powered Data Quality Audit Platform built with Streamlit.

## Features

- 📂 Upload CSV and Excel files
- 📊 Interactive dashboard
- 🔍 Data profiling
- 🧹 Missing value detection
- 🔁 Duplicate detection
- 📧 Email validation
- 📈 Data quality score
- 🤖 AI-powered insights
- 📑 PDF report generation
- ⚡ Optimized for large datasets

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- OpenPyXL

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
